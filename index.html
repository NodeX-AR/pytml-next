Pytml 3 · new engine

Python + HTML.
Keep both simple.

Pytml is a beginner-first browser programming layer. Write normal Python, write normal HTML, and connect them without learning a second application language.

One page, multiple Python programs

<input id="name" placeholder="Your name">
<button id="hello">Hello</button>
<p id="result"></p>

<py1>
def greet():
    result.text = "Hello " + name.value

hello.on("click", greet)
</py1>

py1, py2, py3…

Identifiers, not filenames. Repeat a program tag to continue the same Python state.

Rich browser input

Buttons, text bars, sliders, forms, scrolling, keyboard, mouse, touch, pointer and drag/drop events.

Touch & games

Built-in joystick controls expose position, magnitude and angle for browser games and interactive demos.

Python packages

Keep the familiar micropip workflow. Native packages are built as Pytml WebAssembly wheels.

No Pyodide dependency

Pytml's runtime is designed around CPython compiled directly to WebAssembly with Emscripten.

HTML stays HTML

Use ordinary DOM elements and CSS. Pytml adds conveniences; it does not replace the web platform.


Controls

<btn1> <input1> <textarea1> <range1> <checkbox1> <select1> <joystick1> <canvas1> and media/file/date/time controls are supported by the compiler layer.
